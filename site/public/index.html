Installer Pico

  1. Téléchargez le DMG ci-dessous.
  2. Glissez Pico dans le dossier Applications.
  3. Lancez-le. Au premier lancement, faites un clic droit sur Pico, puis Ouvrir.
Télécharger pour Mac

Apple Silicon · macOS 26 Tahoe ou plus récent

Pourquoi cet avertissement au premier lancement ?

Pico n'est pas encore signé avec un certificat Apple Developer, alors macOS demande confirmation. Le clic droit puis « Ouvrir » suffit. Dans le Terminal, la commande équivalente est xattr -dr com.apple.quarantine /Applications/Pico.app.

Comment vérifier le fichier téléchargé ?

Chaque version publie son empreinte SHA-256. Dans le dossier du téléchargement : shasum -a 256 -c Pico-X.Y.Z.dmg.sha256. Pico fait cette vérification lui-même avant d'installer une mise à jour.

Où sont mes données ?

Dans ~/Library/Application Support/Pico/pico.sqlite. Copiez ce dossier pour sauvegarder. Rien ne quitte votre Mac : le seul échange réseau est la lecture de la dernière version publiée sur GitHub, désactivable.
